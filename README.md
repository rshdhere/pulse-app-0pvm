# Flappy Bird

A classic Flappy Bird game built with Next.js, TypeScript, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to play.

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — run production server

## How to play

Tap, click, or press **Space** / **Arrow Up** to flap. Avoid the pipes and the ground!

## Health check

`GET /health` returns `{ "ok": true }`.
